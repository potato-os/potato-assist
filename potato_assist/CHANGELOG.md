# Changelog

## 0.1.0

- First release.
- Default model `lfm3-1.7b-home-assistant` v0.1, fine-tuned for Home Assistant. Also included: LFM3-VL 2B,
  Bonsai 2 2B and Millie 1.1.
- Ollama-compatible API for Home Assistant's Ollama integration, an OpenAI-compatible `/v1`, a chat UI with vision,
  and Pi 5 telemetry (temperature, throttling, clock, power).
